# Research Archive: Paper Output 2 (Technical Case Study)

This directory contains the archived secondary study (`paper-output2-technical-study/`), previously structured as a separate technical case study examining the three-framework frontend implementation (Bootstrap, Tailwind CSS, Skeleton UI) and associated multi-variant benchmarks.

## Archival Purpose and Provenance
- **Retention**: This secondary study is retained completely intact and unchanged for provenance, historical tracking, and experimental reproducibility.
- **Exclusion**: Per the owner's consolidation directive, this separate technical case study is deliberately excluded from the primary research paper (`research/final-paper/`).
- **Scope Distinction**: The consolidated main paper focuses strictly on freshness-aware, provenance-tracked healthcare resource discovery and request coordination for fragmented urban healthcare information, treating MedReach as an architectural and empirical case study. The three-framework presentation benchmarks (Lighthouse metrics, CSS framework bundle sizes, per-variant render timings) are outside the core contribution of the primary research paper and remain preserved here.
- **Integrity**: All original contents—including `manuscript.md`, `main.tex`, `references.bib`, compiled `main.pdf`, `claim-evidence-audit.md`, `limitations-and-remaining-work.md`, and all associated figures in `figures/`—are preserved exactly in `paper-output2-technical-study/`.
